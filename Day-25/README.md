# 🚀 Day 25 - AI Lead Generation & Outreach Automation | n8n

## 📌 Project Overview

This workflow automates the lead generation process by collecting company information, enriching it with AI, generating personalized outreach emails, and storing the results automatically.

Built using **n8n**, **Google Gemini**, **Google Sheets**, **HTTP Request**, and **Gmail**.

---

## 🎯 Features

- 🔍 Automated company research
- 🌐 Website information extraction
- 🤖 AI-powered company analysis
- 📧 Personalized email generation
- 📊 Lead scoring
- 📄 Google Sheets integration
- 📩 Gmail draft creation
- 🔔 Slack notification support (Optional)

---

## 🏗 Workflow Architecture

```
Manual Trigger
      │
      ▼
Google Sheets (Company List)
      │
      ▼
HTTP Request
      │
      ▼
Google Gemini
      │
      ▼
Extract Lead Information
      │
      ▼
Lead Scoring
      │
      ▼
Google Sheets
      │
      ▼
Generate Personalized Email
      │
      ▼
Gmail Draft
```
